Document Marking Scanner

Point it at a folder of PDF, Word, PowerPoint, Excel and text files. For each one it says whether the document carries an export control warning (ITAR or EAR), whether it carries a CUI marking (Controlled Unclassified Information), and which US government contract number it cites. Then it hands you a spreadsheet with every file name linked to the file. Scanned pages are read with OCR. Everything runs in this browser tab. Nothing is uploaded.

A folder of documents is a scrambled cube. Drop it here and it comes out solved: one row per file, every marking in its place, every file name a click away.

Reads .pdf, .docx, .pptx, .xlsx, .txt and .md, including headers, footers, slide notes and spreadsheet headers. Files never leave this computer. Choose individual files instead.

The browser keeps a folder's location to itself, so by default the spreadsheet links are relative and work when the spreadsheet is saved next to the folder. Paste the folder's full path here and the links will open the files from anywhere on this computer.

A keyword screen, not a compliance determination. The scanner looks for the words and patterns that markings normally use (ITAR, EAR, the DoD export warning, CUI banners and designation blocks, federal contract number formats). A document that says "this is not CUI" will still be flagged, and a marking hidden in an image on an otherwise text page may be missed. Open the row to read the exact text that fired, and treat every Yes and every No as a prompt to look, not a verdict. Legacy .doc, .ppt and .xls files cannot be read here: save them in the modern format first. OCR is best-effort and slow; it runs only on pages with little or no selectable text. Libraries and OCR language data load from public CDNs, but your documents stay in this tab.
