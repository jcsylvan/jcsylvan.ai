Paste the same Bin ID and Access Key on each device to keep this budget in sync. They're stored only on this device (never uploaded to the site or its code). The newer copy always wins, so edit on one device at a time.

One-time setup
  1. Sign up free at jsonbin.io.
  2. Create a bin (any content, e.g. {}) and copy its Bin ID.
  3. Under API Keys → Access Keys, create a key with Read and Update enabled and copy it.
  4. Paste both above, tap save & connect, then repeat on your other devices.
